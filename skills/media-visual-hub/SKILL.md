# 自媒体图片合集

本 Skill 是统一选样与生成入口。样片目录位于 `references/samples.json`，可独立打开的选样库位于 `assets/gallery.html`；所有路径相对本 Skill 目录。`scripts/catalog.py` 仅使用 Python 标准库，可在任意工作目录运行。

## 按用途或编号调用

- 用户给出编号：用 `python3 scripts/catalog.py show 编号` 获取真实样片链接、名称、用途和项目来源。查看图像后再提取风格；不能只凭名称猜测。若不能查看链接，说明情况并让用户附上该样片。
- 用户拿不准：先明确用途和内容，再用 `list --use cover|article|carousel|info|comic|avatar|slides|layout` 查找候选，展示约 3 张实际样片并解释适配点，等用户选。用户已授权自动选择时直接选，不再重复确认。
- 用户只要浏览：打开 `assets/gallery.html`。其中收藏保存在当前浏览器，可复制编号备份；不要假设浏览器收藏已经同步到对话。
- 要制作图片：结合样片、用户内容、平台、比例、准确文案整理生成要求。可用 `brief --style 编号 --content-file 文件 --ratio 比例 --text 图上文字` 生成基础要求。在宿主提供生图能力时实际调用，遵循对应图像工具或 imagegen 技能的使用方式；没有该能力时交付提示词，并如实说明未生成。

参考样片的构图、配色、留白、质感、字体层级，重新设计本次主题；不要照搬样片无关的文字、商标或数据。解释图优先保证逻辑关系准确。所有官方样片只代表原项目示例；不要声称 GPT 已复现或原项目已运行。布局截图和同一风格的不同示例不计为独立画风。

## 原项目能力

已知入口见 `references/projects.json`，包含仓库、固定 commit、真实 SKILL.md 路径、许可证标识；首次需要原项目执行细节时再读取相关入口。

合集根目录的 `upstream/` 是按项目组织的 Git 子模块。它们不会因安装本 Skill 而自动下载。若需要原项目，按 README 中命令初始化对应子模块，读取它的具体 SKILL.md 和依赖说明。不要默认所有项目都能直接调用 GPT；部分需要外部 API、CLI 或浏览器。

本合集不包含发布任务。制作图片不代表授权使用原项目的自动发布功能。

## 满意成品

用户要求保存或当前任务包含归档时，在用户指定目录保存成品与记录：主题、用途、样片编号、参考链接、实际提示词、实际比例/尺寸、实际模型（可获取时）、用户评价。仅把用户确认满意的作品标记为「标准样片」，将本地 GPT 试作与官方示例分开。
